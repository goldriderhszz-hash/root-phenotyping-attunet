## Formatting and submission status

The editable Word file retains the author-requested source typefaces, spacing, margins and page footer. No body line numbering was added. Plant Methods currently requests line and page numbers, so this author-requested deviation remains to be resolved at journal submission; repository organization does not certify every journal requirement. See the [official manuscript instructions](https://link.springer.com/journal/13007/submission-guidelines) and [Methodology instructions](https://link.springer.com/journal/13007/submission-guidelines/methodology).

Data availability, file checksums, research-data terms and reproduction commands are supplied separately. Scientific scope and unresolved author factual confirmations remain as stated in the manuscript. The material is an author-review manuscript, not an accepted article. A GitHub version is not represented as a journal or archive DOI.
