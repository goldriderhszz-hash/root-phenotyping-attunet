# File index

Files are available from [release v1.0.0](https://github.com/goldriderhszz-hash/root-phenotyping-attunet/releases/tag/v1.0.0). The release includes `SHA256SUMS.txt`, a release manifest and a figure manifest.

|File|Contents|
|---|---|
|`Manuscript.docx` / `Manuscript.pdf`|Main manuscript|
|`Additional_file_1_supplement.docx` / `.pdf`|Supplementary information|
|`Additional_file_2_numerical.zip`|Segmentation, descriptor, training-history, CPU timing and reconstruction records; numerical replay scripts|
|`Additional_file_3_geometry.zip`|Seven synthetic masks, reflected inputs and the controlled-study geometry extractor|
|`FIG1`–`FIG8` and `ALG1`–`ALG2`|Independent figures and pseudocode panels in PDF/PNG and available source formats|
|`Figures.zip`|Ten vector PDF figure and algorithm panels|
|`Figure_sources.zip`|Editable PowerPoint sources for Figures 1 and 3|
|`Soybean_rhizobag_dataset.zip`|50 TIFF photographs, 50 LabelMe annotations and 50 merged reference masks|
|`Study_sources.zip`|Study code, prediction masks, protected axes, candidate paths, target matrices and selected-path records|
|`Model_weights.zip`|Five selected D3 checkpoints and 15 fold-specific reconstruction forests|
|`dataset_manifest.csv`|Image IDs, folds, annotation counts, dimensions and file checksums|

The dataset and model archives are hosted as repository downloads. Additional files 2 and 3 are each below 20 MB, and individual figure files are below 10 MB. [Reproduction instructions](REPRODUCIBILITY.md), [data description](../DATA_AVAILABILITY.md) and [data terms](../DATA_LICENSE.md) accompany the files.
