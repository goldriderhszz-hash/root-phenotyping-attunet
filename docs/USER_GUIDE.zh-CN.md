# RootScope Desktop 中文说明

原图和参考掩膜在同一目录时，请只选择原图；整目录导入会包含所有受支持图片，也包括掩膜 PNG。参考掩膜按文件主名匹配，请避免同名掩膜造成歧义。

本说明对应本地候选版本 1.1.0。首次打开默认英文，左下角可选择“中文”。语言不会改变掩膜或描述符数值。

1. 解压完整 Windows 包，保留 EXE 和 `_internal` 文件夹，双击 EXE。
2. 使用“选择图片”“导入文件夹”或拖放导入 TIFF、PNG、JPEG、BMP；不递归导入子目录。
3. 选择 `fold_0` 至 `fold_4`，自动加载该折验证阈值。复现论文时按 `research/fold_assignments.json` 使用各图像对应的留出模型；统一用默认 fold 0 不能替代五折评估。
4. 可选参考掩膜需同名或带 `_mask`、`-mask` 后缀，根白背景黑，尺寸与原图一致；仅用于评估。
5. 选择可写入目录，按需保存概率图，点击“开始分析”。每次创建新的结果子目录。
6. 选择结果行，检查原图、叠加、掩膜和骨架；点击“打开结果”读取 CSV、JSON 和来源记录。

小窗口可滚动设置、结果和表格列。“取消”在当前图像完成后停止。分析时不允许切换语言或模型；空闲切换保留输入、设置、图层和已有结果。系统文件对话框由操作系统决定语言。

优势路径以像素计，不是独立验证的主根长度或总根长；保留线段和候选连接区域不等同于侧根数和真实分枝点。局部锐角受坐标顺序选点规则影响，应作为探索性指标，不能称为已验证萌发角。

新图像可从声明的默认 `fold_0`、阈值 0.47 开始并检查掩膜与质量标记；尚未证明某一折模型对新图像更优。不要用同一套测试标签挑选模型再报告留出性能。固定骨架损失模型是本研究最高 Dice 的误差审计对象，但像素损失 Attention U-Net 的线段和连接区域误差更小，当前五个模型不能据此声称可靠的生物学计数。

输入应保持根系朝下的直立方向。优势路径按最大垂直跨度选择连通分量，不估计解剖学朝向；旋转图像可能改变选择。八邻域对角连接也可能使阶梯状弯曲出现候选连接区域。

“未触发标记”仅表示内置检查没有触发标记，不代表测量准确。“需复核”提示检查细根漏分、额外前景、边界接触和错误连接等问题。

CSV/JSON 字段、单位、模型编号和机器状态保持英文；文件名和路径可含中文。缺失值在 CSV 留空、JSON 为 `null`，不要强行补成零。错误见 `errors.csv`，设置、输入和模型哈希见 `provenance.json`。

```powershell
python cli.py 图片目录 --references 掩膜目录 --output 结果目录 --model fold_2 --language zh --no-zip
RootScope.exe --batch 图像.tif --output 结果目录 --model fold_2 --no-zip
```

EXE 无控制台进度，等待进程结束后读取输出。本地研究资产包尚未公开，不能将“已整理”写成“已公开发布”。
