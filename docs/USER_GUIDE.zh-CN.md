# RootScope 使用说明

RootScope 默认运行论文主要方案 E：D3 三通道分割、操作性轴线保留与有限末端延伸、整根候选、学习评分及计数先验引导的全局解码。该方案是研究原型，所有自动结果均需复核。

将 `RootScope-Windows-x64.zip` 完整解压，打开 `RootScope.exe`，保留旁边的 `_internal`。选择图像或文件夹，模型保持 `auto`，指定输出目录后运行。程序依据图像 SHA-256 识别研究图像并使用对应折及其验证阈值；新图像使用第 0 折并标记需复核。不要将第 0 折理解为全数据生产模型。

表格显示操作性轴线长度（px）、保留路径数、Y 形连接数、三度连接点数、父子路径投影夹角（deg）。这些量不自动等于主根身份、解剖学侧根数量或出根角。缺失值保留为 NA。橙色表示受保护轴线，蓝色表示其他保留候选。

每次输出包含 `Report.md`、CSV、JSON、失败记录、模型来源和哈希、掩膜、叠图及可编辑的 SVG。长度仍为像素；不推测物理标尺。匹配的二值参照掩膜仅用于分割评估，不提供逐根身份真值。取消操作在当前图像完成后生效。复杂图像的图构造和解码可能较慢。

源码运行：`python desktop.py`；批处理：`python cli.py 图像目录 --output 结果目录`。历史流程：`python cli.py 图像目录 --output 历史结果 --pipeline legacy --model fold_0`。英文详细说明见 USER_GUIDE.md；论文一致性和证据边界见 PAPER_ALIGNMENT.md。软件名称不带版本号，提交号和模型哈希保留在来源记录中。
