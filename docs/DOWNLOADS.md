# RootScope Desktop downloads

[Download page](https://github.com/goldriderhszz-hash/root-phenotyping-attunet/releases/tag/rootscope-desktop) · [Source repository](https://github.com/goldriderhszz-hash/root-phenotyping-attunet)

| Package | Contents |
| --- | --- |
| `RootScope-Desktop-Windows-x64.zip` | Windows x64 application, five models, offline guides and license notices |
| `RootScope-Desktop-Source.zip` | Application, research and analysis source, models and numerical evidence |
| `Additional_file_2_Numerical_records.zip` | Numerical evidence and table/figure replay without biological images or model graphs |
| `SHA256SUMS.txt` | SHA-256 checksums for the three archives |

Extract the entire Windows folder and keep `_internal` beside `RootScope.exe`.
No Python or GPU installation is required. Source installation uses Python 3.12
and the pinned requirements. See the [user guide](USER_GUIDE.md).

Identify the software by its exact source commit and executable hash. Model
hashes and thresholds are listed in [MODEL.md](../MODEL.md). The 50-image source
assessment and one-image executable comparison have distinct verification scopes,
as documented in [validation](../validation/README.md).
