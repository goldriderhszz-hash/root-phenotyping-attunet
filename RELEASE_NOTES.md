# RootScope Desktop 1.1.0

English is the default interface, with a Chinese language switch and retained
settings. Scientific column names, units and machine codes remain stable across
languages. The release includes offline user guides, a batch entry point, model
hashes, complete numerical records, portable table/figure analysis, provenance
exports and verification records. Numerical algorithms, models and validation-selected
thresholds are unchanged.

The previous RhizoVision performance comparison is withdrawn because its image
polarity handling did not support a valid comparison. Its reported relative
performance must not be cited. Historical Git commits remain available.
