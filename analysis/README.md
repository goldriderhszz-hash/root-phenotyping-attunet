# Analysis

The segmentation analysis contains the four-configuration, three-seed comparison and the associated skeleton-derived descriptors. Whole-root reconstruction results are in [reconstruction/](reconstruction/), with 250 image/method rows and an aggregation script.

The controlled-study extractor and the contour-guided reconstruction procedure use different measurement definitions. Their protocols, statistical units and diagnostics are defined in the manuscript and [version map](../docs/VERSIONS.json). Record identifiers are retained so that source tables, scripts and model outputs can be linked directly.

[Additional file 2](../manuscript/README.md) provides portable numerical replay. Prediction masks, candidate paths, targets and selected outputs are available in the study-source archive. See [reproduction instructions](../docs/REPRODUCIBILITY.md) for commands and dependencies.
